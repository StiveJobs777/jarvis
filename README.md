# Джарвис: голосовой помощник для ПК (Windows)

Слушает микрофон, понимает русскую речь, выполняет команды на компьютере
и отвечает голосом. Всё, что не похоже на команду, уходит в нейросеть (Groq).

**Как это работает:** микрофон → faster-whisper (речь в текст) → команды или нейросеть → Silero (текст в голос)

## Что нужно

- Windows 10/11
- Python 3.9 или новее
- Микрофон и динамики
- Бесплатный ключ Groq: https://console.groq.com (раздел API Keys)

## Установка

1. Открой PowerShell в папке проекта и поставь зависимости:

   ```powershell
   pip install -r requirements.txt
   ```

   Если `pyaudio` не ставится:

   ```powershell
   pip install pipwin
   pipwin install pyaudio
   ```

2. Сохрани ключ Groq в переменную окружения (один раз):

   ```powershell
   setx GROQ_API_KEY "твой_ключ"
   ```

   После этого **полностью закрой терминал (или VS Code) и открой заново**,
   иначе переменная не подхватится. Проверка:

   ```powershell
   echo $env:GROQ_API_KEY
   ```

   Для разового запуска без сохранения: `$env:GROQ_API_KEY="твой_ключ"`
   (работает только в этом окне PowerShell).

## Запуск

```powershell
python main.py
```

При **первом запуске** скачаются модели (Whisper и голос Silero), это занимает
несколько минут и нужен интернет. Дальше они берутся из кэша.
Когда услышишь «Система запущена», можно говорить.

## Как пользоваться

Все команды начинаются со слова **«Джарвис»**. Если сказать только имя,
он ответит «Слушаю» и воспримет следующую фразу как команду.

| Что сказать | Что произойдёт |
|---|---|
| Джарвис, который час | Скажет время |
| Джарвис, открой ютуб / вк / гугл / википедию | Откроет сайт из списка `SITES` |
| Джарвис, найди рецепт борща | Найдёт в интернете и откроет первую ссылку |
| Джарвис, открой калькулятор / проводник / диспетчер задач | Запустит программу из списка `APPS` |
| Джарвис, открой блокнот | Откроет Блокнот или переключится на него |
| Джарвис, открой новый блокнот | Всегда новое пустое окно |
| Джарвис, запиши | Включит режим диктовки |
| Джарвис, сохрани на рабочий стол под названием список покупок | Сохранит заметку на рабочий стол |
| Джарвис, выключись | Завершит программу |
| Любой другой вопрос | Ответит нейросеть |

### Режим диктовки

После «Джарвис, запиши» (можно сразу с текстом) слово «Джарвис» больше не нужно:
каждая фраза печатается в Блокнот. Чтобы закончить, скажи **«стоп»** или **«хватит»**.
Если в диктовке начать фразу со слова «Джарвис», она выполнится как команда,
а в заметку не попадёт (например, «Джарвис, сохрани»).

Пока идёт диктовка, не кликай мышкой в другие окна: перед каждой фразой
фокус возвращается на Блокнот.

## Структура проекта

```
main.py          главный цикл, слово активации, режим диктовки
listen.py        микрофон и распознавание речи (faster-whisper)
speak.py         озвучка (Silero TTS)
commands.py      команды: сайты, программы, поиск, заметки
notepad_tool.py  работа с Блокнотом (ввод текста, сохранение)
brain.py         ответы нейросети (Groq)
requirements.txt зависимости
```

## Настройка

- **Свои сайты и программы:** словари `SITES` и `APPS` в `commands.py`, одна строка на запись.
- **Точность распознавания:** в `listen.py` модель `"small"` быстрее, `"medium"` точнее (лучше для диктовки, но медленнее).
- **Пауза до конца фразы:** `r.pause_threshold` в `listen.py` (по умолчанию 1.5 секунды).
- **Голос:** `SPEAKER` в `speak.py` (`aidar`, `eugene`, `baya`, `kseniya`, `xenia`).
- **Слово активации:** `WAKE` в `main.py`.

## Если что-то не работает

| Проблема | Что делать |
|---|---|
| `GroqError: api_key client option must be set` | Переменная `GROQ_API_KEY` не задана или терминал не перезапущен после `setx` |
| Не реагирует на команды | Смотри в консоль, что он «Распознал». Команда без слова «Джарвис» игнорируется |
| Плохо ловит слово «Джарвис» | Говори чётче или подними модель до `medium`; порог похожести настраивается в `is_wake()` |
| Ничего не слышит | Проверь микрофон по умолчанию в настройках звука Windows |
| Текст не появляется в Блокноте | Смотри строки `[фокус]` и `[вставка]` в консоли |
| Не находит модель Groq | Актуальные названия моделей в консоли Groq, поменяй `model=` в `brain.py` |
